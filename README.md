# Paanagam Website

A responsive, single-page brand website for **Paanagam (பானகம்)**.

## Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then Save.
4. Wait for the Pages deployment to finish. GitHub will show the published URL on this page.

## Custom domain
Set a custom domain only after confirming that the domain should represent Paanagam. Add it under **Settings → Pages → Custom domain**, then configure DNS with your domain provider and enable HTTPS when available.

## Edit the website
Edit `index.html` to update the brand story, menu highlights, imagery, contact details or links. No build tools are required.
